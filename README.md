## 1. Mini-Max Sum

### Approach

Calculate the total sum of all five values. Subtract the maximum value to obtain the minimum possible sum, and subtract the minimum value to obtain the maximum possible sum.

### Complexity

- **Time:** O(N)
- **Auxiliary Space:** O(1)

### HackerRank

[Mini-Max Sum](https://www.hackerrank.com/challenges/mini-max-sum/problem)

## 2. Birthday Cake Candles

### Approach

Find the maximum candle height and count how many candles have that height.

### Complexity

- **Time:** O(N)
- **Auxiliary Space:** O(1)

### HackerRank

[Birthday Cake Candles](https://www.hackerrank.com/challenges/birthday-cake-candles/problem)

## 3. Insertion Sort – Part 1

### Approach

Take the last element and shift larger elements one position to the right until the correct position for the element is found.

### Complexity

- **Time:** O(N)
- **Auxiliary Space:** O(1)

### HackerRank

[Insertion Sort – Part 1](https://www.hackerrank.com/challenges/insertionsort1/problem)

## 4. Binary Search

### Approach

Use the sorted array and repeatedly divide the search range into two halves. Compare the middle element with the target and continue searching in the appropriate half.

### Complexity

- **Time:** O(log N)
- **Auxiliary Space:** O(1)

### HackerRank

[Intro to Tutorial Challenges](https://www.hackerrank.com/challenges/tutorial-intro/problem)

## 5. Mark and Toys

### Approach

Sort the toy prices in ascending order and purchase the cheapest toys while staying within the available budget.

### Complexity

- **Time:** O(N log N)
- **Auxiliary Space:** O(1)

### HackerRank

[Mark and Toys](https://www.hackerrank.com/challenges/mark-and-toys/problem)

## Reflection

Through these five problems, I practiced important algorithmic techniques including array processing, counting, insertion-based sorting, binary search, and greedy selection. I learned how choosing an appropriate algorithm can improve efficiency and reduce unnecessary operations. The Mini-Max Sum problem helped me understand how a simple one-pass approach can avoid sorting. Birthday Cake Candles strengthened my understanding of finding and counting maximum values. Insertion Sort – Part 1 helped me understand how elements can be shifted efficiently to maintain sorted order. Binary Search demonstrated the advantage of repeatedly reducing a sorted search space, achieving logarithmic time complexity. Mark and Toys showed how sorting combined with a greedy strategy can maximize the number of purchases within a fixed budget. Overall, these problems improved my ability to analyze time and auxiliary space complexity and organize solutions in a structured GitHub portfolio.
